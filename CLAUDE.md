# howtowin.lol

## Python
- Use `uv` for all Python package management (not pip)
- Install packages with `uv pip install`
- Create venvs with `uv venv`

## JavaScript/TypeScript
- Use `bun` for all JS/TS package management and running (not npm/npx)
- Install packages with `bun install` / `bun add`
- Run scripts with `bun run`
